DarkSense AI

An exploration of detecting potentially manipulative interface patterns on websites using browser automation, text classification, visual analysis, and heuristic signals.

Problem

Dark patterns are interface choices that can steer users toward actions they might not otherwise choose. Detection is difficult because relevant signals can appear in text, layout, and interaction flows rather than in one isolated element.

Approach currently described

  • Use Selenium for browser automation and interface inspection.
  • Explore BERT-based text classification.
  • Consider visual signals and heuristic rules alongside text.
  • Keep implementation evidence separate from claims about model performance.

Evaluation and limitations

Detection quality depends on representative labelled examples, clear category definitions, and evaluation that avoids leakage between training and test data. This provisional page does not claim a specific accuracy, precision, recall, or production readiness.

The detailed case study is intentionally deferred until the implementation can be shared. This is not a claim that source code, full setup instructions, or reproducible evaluation are public.
