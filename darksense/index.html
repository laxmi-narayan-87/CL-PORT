Website interface research

Look closer at the web.

Exploring how automation and AI can help identify dark patterns in website interfaces.

DarkSense AI is a project focused on collecting website interface evidence and investigating approaches for detecting potentially deceptive design patterns. The work combines browser automation with machine-learning methods.

Project focus

Interfaces can influence decisions.

The project examines website UI and text for signals that may warrant closer review. A detected signal needs context; it is not, by itself, proof of intent.

  • Browser automation with Selenium
  • Website and screenshot collection
  • NLP exploration for dark-pattern text
01 / About

Make the interface easier to question.

Dark patterns are design choices that can steer people toward decisions they might not otherwise make. DarkSense AI explores ways to surface potentially relevant interface behavior so it can be inspected more carefully.

02 / Approach

Collect evidence first. Interpret it carefully.

The following describes the project's documented direction, not a claim that every stage is deployed as one working service.

STEP 01

Collect

Use browser automation to visit pages, handle page states and capture website interface evidence.

STEP 02

Prepare and analyze

Organize collected information for NLP analysis. Computer vision and multimodal fusion appear in the documented architecture.

STEP 03

Review

Inspect potential signals in context rather than treating an automated prediction as a definitive conclusion.
